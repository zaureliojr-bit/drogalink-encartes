# public/assets/

Arquivos estáticos servidos como estão: artes de cabeçalho, fundos, logos e
imagens de produto que forem hospedadas junto do app.

Imagem servida daqui tem a mesma origem da página, então **entra na
exportação em PNG** sem o bloqueio de CORS que atinge URL externa.

Está vazia de propósito: hoje as imagens entram pelo upload (viram data URL
no navegador) ou vêm do servidor de imagens do padronizador.
